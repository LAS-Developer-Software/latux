# Greeting Extension

A friendly VS Code extension that greets you with your name when you start VS Code. The greeting changes based on the time of day!

## Features

- 👋 Asks for your name on first launch
- 🌅 Shows different greetings based on time of day:
  - 🌄 Guten Morgen (Good Morning) - 6:00 to 11:00
  - ☀️ Guten Tag (Good Afternoon) - 11:00 to 17:00
  - 🌆 Guten Abend (Good Evening) - 17:00 to 22:00
  - 🌙 Gute Nacht (Good Night) - 22:00 to 6:00
- 🔄 Change your name anytime via command palette
- 💾 Saves your name in VS Code settings

## Usage

1. Start VS Code - you'll be asked to enter your name
2. Your name is saved and you'll see a personalized greeting each time you start VS Code
3. Use the "Change Your Name" command from the command palette to update your name

## Commands

- `Greeting: Show Welcome Message` - Display the welcome message again
- `Greeting: Change Your Name` - Change your saved name
